# p41-settings — Налаштування 1:1 з канвасом, з Acceleration

Гілка `design/settings` (від `phase4.1` d5005f9). Борди `Settings` і `SettingsDark` (1440×1819 / 1440×1821), список «Sections» у бічній панелі.

## Що зроблено

- **Сторінка** — тепер повний кадр під верхньою смугою (`SettingsViewModel : IFillsFrame`): колонка до 980 px, поля 32 / 16 / 96, заголовок сторінки, п'ять розділів «заголовок і пояснення | елементи» через гейрлайни. Типографіка й відступи — токени; три нові кроки типів додано в кінець `typeScale` (`subheadingTight` 18/21, `aboutTitle` 20/24 Light, `metaRelaxed` 13/20.8), `Tokens.axaml` згенеровано `TokenGen`.
- **Models** — один список з рамкою: назва, опис, розмір (Geist Mono), чип «Installed», бейдж «Default», прогрес + % + «Cancel», «Download». Усі дії лишилися (Make default, Remove з підтвердженням, помилки, черга пакета AI, вільне місце).
- **Acceleration** (D-042) — картка Surface під списком, сегментований перемикач CPU / Vulkan / CUDA (`AccelerationSettingsViewModel`): варіанти беруться з `IAccelerationProbe`, вибір зберігається через `SettingsWriter` у `AppSettings.Acceleration`; недоступний варіант вимкнений, причина — у підказці (`ToolTip.ShowOnDisabled`); вибір збірки без встановленого runtime одразу завантажує його через `IModelManager` з прогресом, «Cancel» і повтором усередині картки; причина відкату з `IAccelerationStatusSource` (`StartFailed` → «GPU unavailable: …», `RuntimeNotInstalled` → «The Vulkan build is not installed yet…») стоїть під перемикачем; на GPU — «Running on <GPU>».
- **Devices** — три повношироких вибірки з підписами зверху (стиль вибірки онбордингу `ComboBox.onb`), системний звук — «… · loopback».
- **Storage** — поле шляху (Geist Mono, іконка теки), «Change», «Show in Explorer» (і «Reset», коли тека своя), центровано по висоті лівої колонки, як на макеті.
- **Hotkeys** — список з рамкою: Start / stop recording, **Pause**, Toggle screen recording, Open Murmur; кеки Geist Mono; захоплення, очищення й конфлікти — як було.
- **About** — картка з орбом (`OrbDisc`), «Murmur» + версія (Geist Mono), ліцензія проєкту, подяки.
- **Sections у бічній панелі** — клік прокручує розділ до верху (24 px повітря), підсвічується розділ у полі зору (`SettingsViewModel.CurrentSectionId` ← `ScrollChanged` у view; панель оновлює `IsActive` рядків без перебудови). На самому верху сторінки не підсвічено нічого (так на канвасі); після кліку обраний розділ лишається позначеним, доки сторінку не зсунуть; унизу позначено останній.

## Куди пішли налаштування, яких немає на макеті

Шостий розділ **Preferences** (тема, мова інтерфейсу, мова транскрипції «Auto-detect», «Record the screen by default», «Run the introduction again») стоїть **після About** з подвійним проміжком (96 px замість 48). Борд закінчується рівно через 96 px під карткою About, тож розділ лежить за його нижньою межею: жоден намальований розділ не зсунуто, паритет міряється з розділом «нижче About» (не згорнутим). У списку «Sections» він останній. Чому не «Appearance перед About»: це зсунуло б About і зламало б борд; чому не згортати: прихований за прапорцем стан у тестах — це інший екран, ніж користувач бачить. «Record the screen by default» перенесено з Devices: рядок з перемикачем додав би висоти розділу, якої немає на макеті.

Примітки, що були під полями (вільне місце, тека моделей, примітка про пакет AI, «показується весь екран», «Default folder», «нові записи йдуть у цю теку»), перенесено, щоб не зсувати розділи: у ліву колонку під пояснення, текстом у кінець поля шляху, у підказку поля. Дії над встановленою моделлю («Make default», «Remove») показуються при наведенні або фокусі на рядку замість розміру й «Installed» (у спокої рядок = макет).

**Що ще відрізняється**
- Помилка геометрії: «CPU» лівіше на 12.7 px — у макеті «DirectML» (56 px), у застосунку «Vulkan» (44 px), перемикач вирівняно вправо (D-042).
- У шарі форм: стрілки вибірок (власний шеврон замість рідного), внутрішня 0.5-px тінь перемикача в світлій темі (не виражається токенами тіней), кілька пікселів антиаліасінгу орба.
- Виключено з воріт текстів (6): `[VERSION]`, `[LICENSE]`, шлях з `[USER]` (плейсхолдери); «DirectML» (D-042), текст Storage, рядок подяк «Gemma 4 and EmbeddingGemma — Google, Apache 2.0» (EmbeddingGemma — Gemma Terms of Use, а не Apache 2.0) — три задокументовані відхилення в `docs/design/DEVIATIONS.md`. Рядок «Entire display · 1080p30 · hardware H.264» в еталоні не є текстовим вузлом (опція `<select>`); застосунок показує «Entire display · 1920×1080».
- Зайві тексти застосунку (інформаційні): примітки в лівих колонках, розміри моделей, «Preferences» у списку розділів, рядок «llama.cpp · sherpa-onnx · Silero VAD» під карткою About.
- Пікселі всього кадру (22.9 %) — текст Skia проти Chromium, не ворота.
- Сцена: вікно висотою борда; сторінка з розділом Preferences вища (нотатка «A scroll area holds 2348 px…» залишається — решта за межею борда, свідомо).

## Не зроблено / на майбутнє

- Видалення завантаженого GPU-runtime з картки (є лише завантаження) — для цього в `IModelManager` немає зручного імені елемента; ідентифікатори GPU-збірок App виводить із ID CPU-runtime за іменуванням каталогу (`llama-cpp-<tag>` → `llama-cpp-vulkan-<tag>`, `llama-cpp-cuda-<tag>`). Надійніше було б, щоб Core віддавав їх (потребує зміни інтерфейсу — рішення архітектора).
- Windows-перевірка (реальні `WindowsAccelerationProbe`, завантаження 660 МБ CUDA) — лише CI / Windows.
- «Мова транскрипції» — лише «Auto-detect» (як в онбордингу, MVP).
