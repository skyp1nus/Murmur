# Перевірка на Windows: збірка `preview/windows-check`

Тестова гілка лише для власника, її ніколи не мерджать і PR для неї немає. Вона складається з `dev` (до 97a51c1, #98) і чотирьох PR з міткою `needs-windows-check`: #77 (WASAPI-монітор дзвінків), #81 (плаваючий орб), #83 (декодер Media Foundation), #91 (KnownFolder Downloads). Кожна з цих гілок окремо теж оновлена з `dev`. Якщо щось не працює, знайти PR допоможе номер у заголовку групи.

## Команди

```powershell
git fetch origin
git switch preview/windows-check        # уперше: git switch -c preview/windows-check --track origin/preview/windows-check

pwsh scripts/fetch-models.ps1           # моделі для -Asr (Parakeet)
pwsh scripts/fetch-models.ps1 -Ai       # моделі для -AiEval (Gemma 4)

pwsh scripts/verify-local.ps1 -All                              # усе: build, тести, AOT win-x64, старт, інсталятор, -Import, -Capture, -Perf, -Asr, -AiEval
pwsh scripts/verify-local.ps1 -Import -ImportSamples D:\media   # #83: ще й ваші файли з теки (MP3, M4A, FLAC, WMA, AAC, MP4, MOV, OGG, MKV, WEBM)
```

Прапорці окремих PR, якщо треба повторити лише частину (`-All` їх уже містить): `-Capture` (#74, #77, #81), `-Perf` (#78, #81), `-Import` (#83), `-Asr -AiEval` (#93). Під час `-Capture` і `-Perf` має грати щось із мовою, або додайте `-Tone` (гучний тон 440 Гц). Ручні пункти перевіряють у `artifacts/publish/win-x64/Murmur.exe` після `-Publish` (або `-All`). Звіт лежить у `artifacts/local-verify/<час>/report.md`.

### Імпорт: декодер Media Foundation (#66, PR #83)
- [ ] `-Import`: крок `Import` дає PASS. Ці тести мають пройти, а не пропуститися:
  - [ ] `AnAacM4a_IsAudio_AndDecodesTo16kMonoPcm16`: M4A (AAC) розпізнано як `Audio`, тривалість ≈ 3 с, трек 16 кГц моно PCM16 з тоном.
  - [ ] `AnH264AacMp4_IsVideo_WithItsDuration_AndItsAudioDecodesTo16kMonoPcm16`: MP4 розпізнано як `Video`, тривалість ≈ 3 с.
  - [ ] `AnMp4WhoseAudioStartsLate_IsPaddedWithSilence_SoTheTrackStaysInStepWithTheVideo`: перша секунда треку тиха, далі тон. Якщо тон є вже з 0 с, MP4-sink не записав зсув початку.
  - [ ] `MediaFoundationDecoderImportTests.AnMp4AndAnM4a_BecomeSessionsThatTranscribe_TheMp4KeepsItsVideoAsScreenSegmentZero`: MP4 і M4A доходять до `Ready`. У MP4 є `screen-000.mp4` і `ScreenSegment(0, 0, ≈3 с)`, у M4A лише аудіо, мова `uk` доходить до ASR.
  - [ ] `AnMp3_IsAudio_AndDecodes` і `AFlac_IsAudio_AndDecodes`: їх пропускають лише тоді, коли на ПК немає кодувальника MP3/FLAC (причина є в секції «Import: skipped tests»). Тоді MP3/FLAC перевіряє наступний пункт.
  - [ ] `AStereo44kFile_IsProbedAsAudio_AndDecodedTo16kMonoPcm16`, `AVideoWithoutAudio_IsDamaged_NotAnEmptyTrack`, `AFileThatIsNotMedia_FailsCleanly`, `AMissingFile_IsNotFound`, `ACancelledDecode_LeavesNoFile`.
- [ ] `-Import -ImportSamples <тека>` зі справжніми MP3, M4A, FLAC, WMA, AAC (ADTS), MP4, MOV і, якщо є, OGG, MKV, WEBM, 5.1/48 кГц: тест `TheOwnersSampleFiles_DecodeOrAreCleanlyUnsupported` проходить. Кожен файл декодується в 16 кГц моно PCM16 тієї довжини, яку показав probe. OGG/MKV/WEBM без кодеків можуть бути `unsupported on this PC`. Рядок `WARNING: the file declares no duration` означає відому прогалину, для якої є окрема задача.
- [ ] Вручну в Murmur.exe (тепер UI імпорту вже є): імпортований запис знаходиться в пошуку й в Ask AI, а MP4 відтворює своє відео в Recording details.
