# Task p3-llm: Intelligence: llama-server sidecar, IChatClient/IEmbeddingGenerator, LocalLlm, chunker, RAG assistant with timestamp citations

## Scope
src/Murmur.Intelligence/**, tests/Murmur.Intelligence.Tests/**, Directory.Packages.props (only if needed)

## Spec
Decision D-016 (architect): the LLM runs in llama.cpp's `llama-server` as a sidecar process (MIT; Gemma 4 support upstream; process isolation required by CLAUDE.md), talking OpenAI-compatible HTTP on 127.0.0.1 — not LLamaSharp in-process. Release b11716 binaries are reachable here: https://github.com/ggml-org/llama.cpp/releases/download/b11716/llama-b11716-bin-ubuntu-x64.tar.gz (Windows: llama-b11716-bin-win-cpu-x64.zip).
1. LlamaServerProcess: one llama-server child: free localhost port (TcpListener on port 0), args `-m <gguf> --host 127.0.0.1 --port <p> -c <ctx> -t <threads> --no-webui` (+ `--embedding` for the embedding server; check flags against the downloaded binary's --help), waits until GET /health returns 200 (timeout 180 s; early exit -> exception with the stderr tail), Stop = graceful then Kill(entireProcessTree), Dispose kills. On Windows assign the child to a Job object with JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE ([LibraryImport] kernel32, OperatingSystem guards) so it dies with the app. Binary: env MURMUR_LLAMA_SERVER, else <models dir>/llama.cpp/llama-server(.exe).
2. LlamaChatClient : Microsoft.Extensions.AI.IChatClient -> POST /v1/chat/completions, non-streaming and streaming (SSE `data:` lines until `[DONE]`); maps ChatOptions (Temperature, MaxOutputTokens, StopSequences, TopP). System.Text.Json source-generated DTOs only. LlamaEmbeddingGenerator : IEmbeddingGenerator<string, Embedding<float>> -> POST /v1/embeddings (batched), L2-normalized float vectors. EmbeddingPrompts helpers for EmbeddingGemma: query "task: search result | query: {q}", document "title: none | text: {t}".
3. LocalLlm : ILlm with LocalLlmOptions (ChatModelPath = Gemma 4 E4B GGUF Q4, EmbeddingModelPath = EmbeddingGemma GGUF, LlamaServerPath, Threads, ContextSize 8192, IdleUnload 5 min; FromEnvironment() reading MURMUR_LLM_MODEL, MURMUR_EMBED_MODEL, MURMUR_LLAMA_SERVER, MURMUR_MODELS_DIR). Lazily starts each server on the first Get*Async; Status NotInstalled/Unloaded/Loading/Ready; idle unload timer; UnloadAsync stops both. Recording guard: ctor takes Func<bool> isRecordingActive — Get*Async throws InvalidOperationException ("AI is paused while recording") when true, and a public NotifyRecordingStarted() unloads immediately (models never stay in memory during recording).
4. TranscriptChunker: Transcript -> TextChunk list of 30–60 s windows along segment boundaries (a single segment > 60 s becomes its own chunk), lines prefixed with the speaker label ('Я:' for Me, 'Інші:' for Others); deterministic; Start/End = first/last segment times.
5. Assistant : IAssistant (ctor ILlm, IStorage, AssistantOptions). IndexSessionAsync: GetTranscriptAsync -> chunk -> embed with the document prompt in batches of 16 -> ReplaceChunksAsync. SearchAsync: SearchKeywordAsync top 20 + SearchVectorAsync(query-prompt embedding) top 20 -> Reciprocal Rank Fusion (k = 60) -> top `limit`, merging keyword (segment-level) and vector (chunk-level) hits that overlap in time within the same session; Source = Hybrid. AskAsync: retrieve top 6 within scope; prompt with a Ukrainian system prompt: answer only from the excerpts, in the language of the question, cite every claim with the excerpt timestamp in square brackets like [12:34] ([1:02:03] above one hour), say plainly when the answer is not in the recordings; excerpts formatted 'Уривок N — «<session title>», [mm:ss–mm:ss]:' + text (titles via GetSessionAsync); include History; stream AssistantUpdate(delta, [], false); at the end parse citations with \[(?:(\d+):)?(\d{1,2}):(\d{2})\], resolve each to the best-ranked retrieved chunk whose [Start-15 s, End+15 s] contains the time -> Citation(session, at, label, snippet ~120 chars around); dedupe; if nothing resolves, add the top excerpt's start as a fallback citation; final AssistantUpdate("", citations, true). Use plain async code; this is not a hot path.
6. Tests (tests/Murmur.Intelligence.Tests): fake OpenAI-compatible server (HttpListener on 127.0.0.1, random port) for chat (non-streaming, streaming SSE incl. split chunks, HTTP errors) and embeddings (batching, normalization); LlamaServerProcess with the real downloaded llama-server binary started without a valid model -> clear error with stderr tail (download the ubuntu tarball into a temp dir in a test fixture only if reachable, otherwise skip with a message) and with a fake script that serves /health (python3 -m http.server style is fine) for the happy path; chunker; Assistant with fake ILlm/IChatClient/IEmbeddingGenerator/IStorage: RRF ordering, scope filtering, citation parsing/resolution (hours, out-of-range, multiple sessions, dedupe), fallback citation, recording guard, idle unload.
Real Gemma 4 + EmbeddingGemma end-to-end runs later in GitHub Actions (Hugging Face reachable there); keep everything configurable via env for that.
