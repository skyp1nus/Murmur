# Task p1-recording-ui: Library + Recording screens (orb, pill toggles, timer), composition root, --autorecord perf mode

## Scope
src/Murmur.App/**, src/Murmur.Desktop/**, tests/Murmur.App.Tests/**, docs/screenshots/**

## Spec
1. Shell navigation Library <-> Recording via a ShellViewModel with CurrentPage and DataTemplates keyed by x:DataType (no reflection ViewLocator).
2. Library screen: sessions from ISessionStore.ListSessionsAsync (title, date, duration in Geist Mono, small badges for mic / system / screen), pill filter Сьогодні / Тиждень / Усі, the phase-0 empty state when empty, primary pill 'Новий запис' -> Recording. Virtualized list.
3. Recording screen (docs/PLAN.md 'Екрани MVP' #2): OrbControl (src/Murmur.App/Controls/OrbControl.cs — the only place Violet/Ember brushes are allowed): soft radial-gradient blob Violet->Ember that 'breathes' (scale + glow) from the smoothed audio level (max of mic/system); animates via the render loop ONLY while recording (idle = static frame, zero CPU); no per-frame allocations (cache brushes/geometries). Pill ToggleButtons Мікрофон / Системний звук / Екран (achromatic ToggleButton.pill style: Ink fill when checked, outline otherwise) — before recording they choose sources; while recording only Екран is enabled (IRecorder.SetScreenEnabledAsync). Timer HH:MM:SS in Geist Mono from IRecorder.Elapsed. Primary pill 'Почати запис' / 'Зупинити'. Device ComboBoxes (mic, output) from ICapture.GetAudioDevices. Caption: 'Попередь учасників мітингу, що йде запис.' Errors inline. One DispatcherTimer (~4 Hz) or the orb's render tick polls IRecorder.Levels/Elapsed — no per-buffer events.
4. Murmur.Desktop composition root (pure DI): SqliteStorage (Murmur.Storage, data root from StoragePaths), capture = WindowsCapture on the windows TFM, SyntheticCapture on net11.0; Recorder(capture, storage, TimeProvider.System, default settings); RecoveryService run at startup (off the UI thread) before the library loads; pass interfaces to App view models. Murmur.App still references Murmur.Core only (ArchitectureTests must pass).
5. Automation/perf mode used by CI: `Murmur.exe --autorecord <seconds> [--screen] --perf-out <json>`: shows the UI, measures 10 s idle CPU first, then starts recording (system loopback + default mic if one exists; skip a missing mic gracefully; --screen enables the screen), samples once per second off the UI thread: process CPU = delta TotalProcessorTime / wall / Environment.ProcessorCount (% of whole machine) plus % of one core, WorkingSet64 and PrivateMemorySize64; stops after <seconds>, writes JSON {durationS, idleCpuPct, cpuAvgPct, cpuP95Pct, cpuAvgPctOneCore, wsAvgMb, wsMaxMb, privateMaxMb, recorderStats{microphoneFrames, systemFrames, droppedFrames, screenFramesDropped}, session{id, folder, micSeconds, systemSeconds, screenSegments}} with a System.Text.Json source-generated context, exits 0 (non-zero + error field on failure).
6. Screenshots with Avalonia.Headless (Skia): docs/screenshots/phase1-library.png (with a few fake sessions), phase1-recording-idle.png, phase1-recording-active.png (fake recorder with levels). Look at them and fix layout issues.
7. Tests: view-model tests with fakes (start/stop flow, toggles locked during recording except Екран, timer formatting, error display, library filters); the accent-guard test still passes (OrbControl allowed).
