# Дизайн

Поклади сюди експорт макетів (PNG), по одному файлу на екран:

| Файл | Екран |
| --- | --- |
| `01-library.png` | Бібліотека записів |
| `02-recording.png` | Запис (сфера, перемикачі, таймер) |
| `03-recording-view.png` | Перегляд запису: плеєр + транскрипт |
| `04-ai-chat.png` | AI-чат із таймкодами |
| `05-settings.png` | Налаштування |

Посилання на Figma (якщо є): _додай сюди_

`tokens.json` — джерело правди для кольорів, шрифтів, радіусів і відступів. Якщо макет розходиться з токенами — перемагають токени.
